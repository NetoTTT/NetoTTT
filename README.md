# NetoTTT

Software developer building web, mobile, desktop, and IoT systems — freelance, end to end.

### Currently working on

- [YTune](https://github.com/NetoTTT/YTune) — native desktop YouTube Music client
- [Klaver](https://github.com/NetoTTT/Klaver) — MIDI-based piano learning app

### Technologies

**Languages:** Java, Kotlin, TypeScript, Rust, Python
**Backend:** Node.js, Firebase, MySQL, PostgreSQL 
**Systems / IoT:** C/C++, ESP32, FreeRTOS

### Selected Projects

**[YTune](https://github.com/NetoTTT/YTune)**
Native YouTube Music desktop client (Rust, Tauri) with Discord Rich Presence and system tray controls.

**[Klaver](https://github.com/NetoTTT/Klaver)**
Piano learning app for Windows with MIDI playback and a built-in SF2 synthesizer.

**[HaskShop](https://github.com/NetoTTT/HaskShop) / [HaskCash](https://github.com/NetoTTT/HaskCash)**
Backend plugin suite for Minecraft servers: GUI shops, a currency system with a public API, rankings.

**[eximg](https://github.com/NetoTTT/eximg)**
Lightweight always-on-top reference image viewer for artists, written in Rust.

**[Smart Signal](https://wokwi.com/projects/409408010658307073)**
ESP32 traffic light that prioritizes flow based on real-time lane occupancy.
